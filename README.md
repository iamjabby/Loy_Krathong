# ลอยกระทง ลอยใจ — Bingo Night

เว็บบิงโก 5×5 สำหรับเล่นคนเดียวบนมือถือหรือคอมพิวเตอร์ ธีมงานวัดยามค่ำคืนในโทนส้มอิฐ เขียว น้ำเงิน และประกายแสงโคม

## เริ่มใช้งาน

```bash
npm install
npm run dev
```

เปิด `http://localhost:3000` เพื่อเล่น

## นำขึ้น Vercel

นำโฟลเดอร์นี้เข้า Vercel แล้วใช้ค่าตั้งต้นของ Next.js ได้เลย ไม่ต้องตั้งฐานข้อมูลหรือตัวแปรสภาพแวดล้อม

## พฤติกรรมข้อมูล

ชื่อเล่น บอร์ด และช่องที่ทำเครื่องหมายอยู่ในหน่วยความจำของหน้าเว็บเท่านั้น ไม่มีบัญชี ห้อง หรือฐานข้อมูล การออกจากเกมหรือรีโหลดหน้าจะเริ่มใหม่ การดาวน์โหลดสร้างไฟล์ PNG ในเบราว์เซอร์โดยตรง
